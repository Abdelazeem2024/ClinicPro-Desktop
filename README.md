# Clinic Pro — نظام استقبال وتنظيم العيادة

برنامج سطح مكتب احترافي لإدارة استقبال العيادات الطبية.

## المميزات

- شاشة رئيسية أنيقة بإحصائيات اليوم
- تسجيل مرضى سريع مع تنبيه التكرار
- دخول مريض (كشف / إعادة) + طابور منظم
- حفظ تلقائي فوري (ضد انقطاع الكهرباء)
- تقارير محمية بكلمة سر (افتراضي: 1234)
- إعدادات الهوية البصرية (اسم + شعار + لون + Dark/Light)
- تصدير واستيراد كامل JSON
- تصميم عالمي فاخر RTL عربي

## التشغيل للتطوير

```bash
npm install
npm run electron:dev
```

أو للويب فقط:

```bash
npm run dev
```

## بناء نسخة سطح المكتب

```bash
npm run dist
```

ستجد الملفات في مجلد `release/`.

## نظام التجربة والتفعيل (جديد)

- نسخة تجريبية 3 أيام من أول تشغيل، بعدها يتوقف البرنامج عن العمل ويطلب كود تفعيل.
- شاشة التفعيل تبقى تعمل دائمًا حتى أثناء الحظر (لا يتوقف زر "تفعيل" أبداً).
- التحقق بتوقيع رقمي Ed25519 (نفس نظام أداة `agriplus-activator`، مسجَّل كمنتج
  مستقل باسم `PROD-001` — لا علاقة له بأي منتج آخر تديره من نفس الأداة).
- معرّف الجهاز يظهر وقابل للنسخ من الإعدادات → "الترخيص"، أو من شاشة الحظر مباشرة.
- `electron/license.cjs` يحتوي المفتاح العام فقط (آمن للتوزيع). المفتاح
  الخاص يبقى فقط داخل أداة التفعيل عندك ولا يُشحن مع البرنامج إطلاقاً.
- لتوليد كود لعميل: افتح أداة `agriplus-activator`، اختر برنامج
  "ClinicPro - نظام العيادات"، الصق معرّف الجهاز، واضغط "تفعيل".



- Electron

- CSS متغيرات للثيم الديناميكي (ألوان النصوص تتغير تلقائياً حسب الوضع الفاتح/الداكن)

## إصلاحات النسخة الحالية

- إصلاح جميع أخطاء Template Literals (backticks) التي كانت تمنع البناء
- إصلاح `import type` للتوافق مع verbatimModuleSyntax
- تقوية التحقق من صحة ملف JSON عند الاستيراد
- استبعاد الحالات الملغاة من عرض الطابور (مع بقاء الإحصائيات صحيحة)
- تفعيل لون الخلفية الاختياري من الإعدادات
- تعديل مسار الأيقونة في electron-builder ليتوافق مع الملفات الموجودة

## تحديثات جديدة

- أيقونة سطح المكتب الجديدة (من الصورة المرفقة) واضحة وعالية الجودة
- طباعة تذكرة الدور:
  - زر "تسجيل + طباعة تذكرة الدور"
  - بطاقة سريعة بعد التسجيل مع زر "طباعة تذكرة الدور"
  - زر طباعة بجانب كل مريض في الطابور
  - خيار طباعة تلقائية من الإعدادات
  - تصميم بسيط متوافق مع طابعات حرارية 58mm / 80mm والعادية
